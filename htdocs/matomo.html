Request a Matomo analytics property

The ASF runs its own Matomo instance for privacy-friendly web analytics. Use this form to set up a new Matomo property (site) for one of your project's websites. You will get a site ID and the tracking code to add to your pages. Both are also sent to your project's private mailing list. Reports for all ASF properties are publicly viewable.

Select the project this site belongs to. You can only request properties for projects whose PMC you are on.
The address of the site to track. It must be on your project's domain (project.apache.org) or one of its subdomains, for instance https://project.apache.org or https://project.apache.org/docs.
Sites other than the project's main website need a short label (up to 40 letters, digits, spaces, dots or dashes).
